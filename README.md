# Конструктор обитаемых планет

Интерактивный веб-сайт, который позволяет создавать планеты и оценивать их пригодность для жизни.

Пользователь настраивает параметры:
- Тип звезды и расстояние до неё
- Долю океанов
- Атмосферное давление и содержание кислорода
- Силу тяжести
- Наличие магнитного поля и уровень радиации
- Наличие крупного спутника

Система в реальном времени рассчитывает примерную температуру поверхности и выдаёт оценку пригодности планеты (от 0 до 100 %) с подробными пояснениями.

### Готовые пресеты
- Реальные миры: Земля, Луна, Марс, Венера, Титан, Ганимед, TRAPPIST-1e (За пределами солнечной системы).
- Из фантастики: Корусант (Звёздные Войны; столица Галактической Республики, а затем и Империи), Татуин (Звёздные Войны; пустынная планета за пределами Республики и Империи), Святая Терра (Warhammer 40.000; Земля в 42-ом тысячелетии), Кадия (Warhammer 40.000; Планета-крепость, которая была разрушена силами Хаоса).

### Технологии
- HTML5
- CSS3
- Vanilla JavaScript (без фреймворков)
